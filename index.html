Why Spec Editor

Active Memory Layer for AI-driven development

Unlike passive docs, this memory is alive. AI agents continuously debate, cross-reference, and evolve the project knowledge — turning requirements into a structured, version-controlled knowledge base.

Multi-agent debate

AI agents and an orchestrator discuss your requirements from different angles. They challenge each other, fill gaps, and build consensus — eliminating single-perspective blind spots.

Methodology-driven structure

Not a flat list. Modules, scenarios, entities, UI, metrics — all connected with typed relationships. Define your own aspects and relationships in YAML. Waterfall, Agile, API-first — swap methodology without rewriting your spec.

MCP for coding assistants

Connect to Claude Code, Cursor, or Zed via MCP. Your AI coding agent gets the full specification as context — generating code aligned with your requirements.

VS Code Extension

Browse your spec in a tree view, generate Mermaid diagrams (ER, Class, Flowchart, Sankey — 8 types), edit elements with live preview. Available on the VS Code Marketplace. Prototypes exist for JetBrains and Zed — ready for community contributors to finish and polish.

Export & Semantic Search

Export to SRS (IEEE 830), HTML, OpenAPI 3.0, Jira CSV, or Compliance XLSX. Semantic code search finds functions by meaning, not just by name — your AI agent understands the codebase without reading every file.

Quick Start

Three steps to structured specs

From messy documents to a connected specification your AI can use.

1

Add your requirements

echo "Users log in via email..." > source/auth.md

Drop Markdown, TXT, PDF, or chat logs into source/. The pipeline extracts and classifies requirements.

2

Run the agents

spec-editor run

Multi-agent debate produces a structured specification with typed relationships — 8 aspects in the default waterfall methodology.

3

Explore & connect

spec-editor mcp &

Start the MCP server, then install the VS Code extension for interactive diagrams and tree view. Or connect Claude Code, Cursor, or Zed directly via MCP.
